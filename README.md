# Gaffer

The manager's second screen for EA SPORTS FC 27 Career Mode.

Gaffer reads your career save (it never changes it) and analyses your squad: best XI and line-up fixes, FC IQ roles and tactics, transfer targets that fit your budget, rotation, contracts and youth development. It updates itself after every match while you play.

## Download

Go to **[Releases](../../releases/latest)** and download `Gaffer-Setup-<version>.exe`.

## Install

1. Run the installer. Windows may say "Windows protected your PC" because the app is not code-signed yet: click **More info**, then **Run anyway**.
2. Open Gaffer and import your career save (`Documents\EA SPORTS FC 27\settings\CmMgrC…`).
3. On the PC where FC 27 is installed, Gaffer reads player names from the game files on first launch (a few minutes, then cached).
4. Turn on Autosave in FC 27, then in Gaffer open **Season timeline** and click **Follow this career**.
